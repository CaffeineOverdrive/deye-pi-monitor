    For safety the monitor can't see any USB devices until you choose the adapter. On the Pi run ~/deye-pi-monitor/enable-rs485.sh: it asks you to unplug and re-plug the adapter, so it can never pick your 3D printer or anything else. Then press Refresh.

    Home Assistant (optional)

    The Pi sends live readings to Home Assistant through an MQTT broker. If Home Assistant runs its Mosquitto broker add-on, press Find broker; a Deye inverter device then appears in Home Assistant automatically.

      Use a broker-only login: in Home Assistant add one under Settings → Add-ons (called Apps in newer versions) → Mosquitto broker → Configuration → Logins (e.g. deye-monitor), restart the add-on, and enter it here. Avoid a Home Assistant person's login: it also opens the Home Assistant app.

      No Home Assistant broker?

      Install the Mosquitto broker add-on in Home Assistant (recommended), or start a broker on this Pi by running ~/deye-pi-monitor/enable-broker.sh, then press Find broker again. For the Energy dashboard use Grid import total, Grid export total, PV energy total and Battery charge/discharge total.
